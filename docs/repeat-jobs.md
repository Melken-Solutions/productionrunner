# Run a previous job again

Planners and organization admins can open a job ticket or production-lot dashboard and choose **Run this job again**. Review the source job’s manufacturing route, enter a new quantity and delivery date, and enter new organization-configured ERP references. **Create repeat draft** opens a new editable production request; it does not release production or allocate a JobRunner ID yet.

The draft copies the actual job’s operation order, work instructions, acceptance checks, first-piece requirements, DXF requirement, material and material notes, outside vendor instructions, and final inspection/packing/shipping checks. It does not silently substitute a newer saved part template. Customer/destination are suggestions for review. An inactive station is cleared for reassignment; inactive material must be selected again. Changed material versions remain subject to the existing approval checks. The preview flags other drawing revisions, changed document packages and different saved part-plan versions.

Prior ERP references, source-order references, delivery schedules, vendor PO/return dates, sheet quantity estimates, HOT priority, assigned people, serial numbers, progress, timings, approvals, inspection results, shipment labels and dispatch records are not copied. Organization custom fields are not copied because they can contain order-specific data; review required shop details before approval. Configure quantity tracking and new lots/serials when converting the new approved request.

The new request retains a **Repeated from** link and an immutable audit event. That link also appears on its eventual job. Saving and approval use the existing checks; missing outside return dates block approval. Creating the same reviewed draft twice returns the same draft. Source/catalog changes during review require reopening the shortcut. The source job is never modified. Legacy jobs without a controlled plan require completion of missing checks. Multiple outside steps require manual planning.
