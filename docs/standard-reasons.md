# Standard reason choices

Change forms use a contextual Reason dropdown for administration, access, planning, catalog changes, shipping, quality and time corrections. No choice is preselected. Common choices submit without typing. Additional details are optional; Other requires an explanation. Details are limited to 400 characters so the combined label and notes fit existing audit fields.

The server validates submitted choice values and records the chosen label plus notes in the existing audit trail. Authorization, confirmations, version checks and approvals still apply. Existing integrations that submit a free-text `reason` remain compatible. Changing these UI controls does not rewrite historical audit records.

Station interruption configuration offers common reasons to add, excluding reasons already available. Other allows an admin to define a new reason. Operators continue choosing from the existing controlled interruption list.

Actual inspection results, measurements, repair instructions and return-closure evidence are not replaced by generic reasons. Selecting a reason does not assert that a required inspection or review has passed.
